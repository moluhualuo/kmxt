# 管理后台

> 0.6.0：程序列表支持 Android 配置下载；后台已接入 Dashboard、商户资料编辑、程序设置编辑、账号启停、卡密批次记录，以及订单和日志的筛选。下载接口仍执行登录角色与程序租户权限校验，绝不包含签名私钥。

## 0.6.0 后台接线

- 总览调用 `GET /api/v1/dashboard`，按当前商户和程序上下文显示订单、卡密、绑定及 24 小时验证统计。
- 商户页可仅修改名称；唯一代码只读。
- 程序页可修改名称、说明和授权/设备/心跳/离线宽限设置；程序代码和签名密钥保持只读。
- 账号页可重置密码、启停非当前账号；停用确认会明确提示管理会话被撤销。
- 卡密页可查看批次元数据；平台管理员和商户管理员可显式查看单张完整卡密，操作会写入审计记录。
- 订单页支持状态、订单号和时间范围；日志页支持动作或验证事件/结果及时间范围。

后台视图已拆分为 `public/js/views/overview.js`、`merchants.js`、`applications.js`、`licenses.js`、`products.js`、`orders.js`、`users.js` 和 `logs.js`。`views/shared.js` 提供一致的页面标题、权限判断、表格格式化和视图依赖；按钮、分页、对话框和转义组件继续位于 `public/js/components.js`。

管理后台由 Node.js 服务直接提供，入口为 `/admin/`。它使用原生 HTML、CSS 和模块化 JavaScript，不依赖 CDN 或前端构建工具。作者花落，项目代码使用 MIT 协议；Lucide 图标许可单独记录在 `public/assets/ATTRIBUTION.md`。

| 商户 | 创建、进入、启停 | 不显示 | 不显示 |
| 程序 | 创建、查看、启停 | 创建、查看、启停 | 查看 |
| 卡密 | 生成、查询、启停、解绑、查看完整卡密、删除 | 生成、查询、启停、解绑、查看完整卡密、删除 | 生成、查询、启停、解绑 |
| 商品 | 创建、编辑、启停 | 创建、编辑、启停 | 查看 |
| 订单 | 审核、发卡、拒绝 | 审核、发卡、拒绝 | 审核、发卡、拒绝 |
| 账号 | 创建、查看和重置密码 | 创建、查看和重置密码 | 不显示 |

| 程序验证日志 | 查看 | 查看 | 查看 |

平台管理员通过顶部商户选择器切换租户。商户账号的租户来自登录会话，不能在界面切换到其他商户。

所有角色都可通过侧栏账号区的钥匙按钮修改自己的密码，需提供当前密码。平台管理员和商户管理员可在“账号”表格重置其有权管理的其他商户账号密码。改密或重置成功后，目标账号的所有后台会话都会立即失效。

## 核心流程

### 创建授权业务

1. 平台管理员在“商户”创建商户并进入。
2. 在“账号”为商户创建管理员或操作员。
3. 在“程序”创建程序并设定默认天数、设备数、心跳及离线容忍。
4. 在“卡密”选择程序并生成批次。
5. 生成表单关闭后展示一次性结果，可复制或导出文本。

### 卡密和设备

卡密页面支持程序切换、状态筛选、完整卡密精确查询和分页。启停卡密会弹出风险确认。平台管理员和商户管理员可在二次确认后查看完整卡密或删除未关联订单的卡密；查看与删除均会写入审计记录。删除会撤销全部客户端会话、清除设备绑定和验证记录。设备按钮显示绑定历史；可单独解绑活动设备，也可在存在活动绑定时使用“解绑全部设备”。批量解绑会立即撤销该卡密的全部客户端会话、保留绑定历史并写入一条卡密级审计记录。

### 日志

“日志”使用分段控件切换管理审计与程序验证记录。操作员只能看到程序验证记录。所有列表按当前商户或程序范围查询。

### 商品和订单

“商品”按当前程序配置店铺套餐，包括展示价格、授权天数、设备上限、排序和启停状态。设备上限填 `0` 表示无设备绑定上限，默认仍为 1 台。“打开店铺”在新标签页进入当前商户的公开页面。

“订单”按商户分页和筛选，并使用订单专属状态文字区分“待处理、已发卡、已拒绝”。待处理订单可以发卡或拒绝；发卡会自动创建一张对应程序卡密，重复提交不会重复生成。已发卡订单可复制卡密，客户同时可以在公开店铺凭查询码领取。

## 会话与安全

- 管理令牌保存在 `sessionStorage`，关闭标签页后清除，不写入 URL。
- 所有 API 数据在插入 HTML 前通过 `escapeHtml` 转义。
- `401` 响应会清除本地会话并返回登录页。
- 修改本人密码成功后主动返回登录页；管理员重置密码后目标账号必须重新登录。
- 静态资源使用 CSP，仅允许同源脚本、样式、图片和 API 请求。
- 卡密列表与批次记录不显示明文；仅平台管理员或商户管理员在二次确认后可按单张卡密显式查看，且每次查看均留有审计记录。
- 管理后台不能替代 HTTPS；公网部署必须由反向代理终止 TLS。

## 响应式与无障碍

- 桌面使用 244px 固定侧栏和数据表布局。
- 侧栏账号名称与密码、退出操作分行布局，长名称保持可读且不挤压图标按钮。
- 桌面隐藏移动菜单按钮；820px 以下侧栏变为可关闭抽屉，窄屏顶部栏隐藏重复标题并为商户选择器保留固定空间。
- 登录页在 820px 以下切换为受 `100vw` 限制的单列布局；表单使用零最小宽度约束，表格只在自身容器内横向滚动，不扩张页面。
- 所有主要按钮至少 40px，高频图标按钮为 42px；移动导航操作区域不小于 44px。
- 表单输入均有显式标签；图标按钮具有 `aria-label` 和悬停标题。
- 键盘焦点使用高对比描边，对话框使用浏览器原生焦点管理。
- 支持 `prefers-reduced-motion`，减少动画用户不会看到持续过渡。
- 状态同时使用文字和颜色，不以颜色作为唯一信息。

## 运行态验收

Windows 环境可使用本机 Chrome 或 Edge 执行真实浏览器验收：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/ui-smoke.ps1 `
  -Username admin -Password "管理员密码" `
  -Width 375 -Height 812 -Screenshot .runtime/mobile.png
```

公开店铺无需登录：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/ui-smoke.ps1 `
  -Public -Path /store/MERCHANT_A `
  -Width 375 -Height 812 -Screenshot .runtime/store-mobile.png
```

公开店铺的已发卡查询状态可附加 `-StoreOrderNo` 和 `-StoreQueryCode`；两个参数必须同时提供，脚本会提交真实查询表单并等待卡密交付或拒绝结果。

脚本通过 DevTools 设备指标创建精确 CSS 视口，可提交真实后台登录表单或等待公开店铺加载，检查文档宽度是否超过视口，并保存 PNG 截图；后台截图后主动退出本次管理会话，随后关闭测试浏览器并删除临时配置。标准输出仅返回验收 JSON，密码只用于当前测试进程且不写入文件。


## 2026-07-17 卡密批量删除与分页显示

作者：花落；协议：MIT。卡密列表支持勾选当前页卡密后批量删除，按钮在未选择时禁用，执行前二次确认。批量删除调用 `POST /api/v1/apps/:appId/licenses/bulk-delete`，后端对每个卡密逐个执行订单保护、租户隔离、会话撤销、设备绑定清理和审计写入；已关联订单的卡密不会被删除，并在结果中显示为失败项。

卡密列表新增每页显示数量选择，支持 20、50、100。前端切换每页数量时会回到第一页并清空已选项；后端 `parsePagination` 继续强制 `limit <= 100`，避免一次请求加载过多数据。
